# 第四阶段 · 搜索与写作

开发分支 `feat/search-authoring`。在[生产样文预览](http://127.0.0.1:4355/search/)输入「文件夹」查找正文，输入「知识整理」匹配标签。打开结果后点击标签，刷新页面仍可看到对应文章。「散步」仅出现在生活草稿中，搜索结果为空。

7 项单元测试、5 项 Chrome 浏览器测试通过。验证了生成默认草稿、上海日期、目录碰撞保护、标签规范、中文查询、标签深链接和既有阅读功能。生产构建复核了撤回最后一篇文章后的空状态和旧索引清理。正式内容目录仍为空，预览使用验收素材。

日常创建、预览、发布和撤下操作见[写作指南](../writing.md)。
